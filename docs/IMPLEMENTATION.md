# 实现与验收记录

## P0 审计

原始仓库无提交、分支或源码，无既有架构可复用。已新建 Python 标准库 HTTP 服务、SQLite 数据层及中文浏览器界面。前后端同源；本地单用户模式。

## 已实现功能

| 需求 | 实现 | 限制 |
|---|---|---|
| B01 项目启动 | 条件、预算、阶段任务、启动卡、条件更正、项目导出 | 启动卡由规则程序生成；还不是自由对话提取条件 |
| B02 机会探索 | 证据录入、分类、模型分析、真实来源闸口 | 没有外部检索；有来源文本不等于来源已自动核实 |
| B03 商品验证 | 商品供应与人工样品记录、前置依赖 | 没有供应商接口或文件上传 |
| B04 财务风险 | 整数金额、缺失成本、风险记录、验收阻拦 | 风险记录需人工核查；无专业风险自动审查 |
| B06 营销 | 计划、受众、渠道、页面、观察条件、预算与人工费用记录 | 不执行真实投放；本地预算限制不控制外部平台 |
| B08 订单 | 人工导入、防重复、支付核查状态、物流、售后、退款重新计账 | 不获取实际支付或物流状态；客户工单尚未实现 |
| B09 复盘 | 假设、改动、观察条件、结果、下一步记录 | 不自动判断统计显著性，不自动执行改动 |
| 任务执行 | 数据库队列、版本成果、幂等入队、有限次数授权、失败显式重试、暂停与重启恢复 | 单进程 worker；无多租户隔离 |

## 验收证据范围

`tests/test_workflow.py`：成本未知、精确计算、前置依赖、返工与持久化、项目归属检查。

`tests/test_execution.py`：本地真实执行、重复执行、无凭据阻拦、无证据阻拦、调用次数与撤销、模型协议与假引用拒绝（受控响应）、执行中断恢复、人工接管、条件变化导致旧结果失效；另覆盖订单重复、履约状态、退款、活动预算和数据不足复盘。

`tests/browser.cjs`：浏览器创建项目、执行项目卡、查看成果、验收解锁、录入来源、营销计划、测试订单、页面导航、移动宽度和 JS 异常检查。使用测试数据库，所有业务内容标记 TEST，不表示真实市场证据。

未运行真实模型、站点、获客、订单或经营反馈验收；不能声称 T01–T18 全部通过。当前 T07 外部发布幂等、T16 跨用户隔离及 T18 真实闭环尚不支持。

## 下一阶段依赖

1. 模型密钥与目标模型，用于真实模型兼容性和失败行为验证。
2. 明确首个站点及一个获客渠道，按官方接口实现连接与授权；当前没有已接通账号。
3. 多用户认证和租户隔离后才能向外提供服务。
4. 接入外部写操作前，实现外部操作账本、审批、结果查询与恢复，不以本地订单号幂等替代外部动作幂等。

## 回滚

停止服务后备份数据库与源文件；代码回滚前检查表结构兼容。当前新增表均采用 IF NOT EXISTS，不自动删除用户记录。恢复副本经任务重启与状态检查验证。
