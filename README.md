# 启航 · 独立站 AI 创业与经营中台

从空仓库开发的可运行版本。原始需求见 [产品规格](docs/PRODUCT_SPEC.md)，实现进度见 [交付与验收](docs/IMPLEMENTATION.md)。

## 启动

Python 3.12+，运行代码仅使用标准库。没有第三方运行依赖。

```sh
python3 server.py
```

默认监听本机 3000 端口；`PORT` 更换端口，`APP_DB` 指定 SQLite 数据库路径（默认 `.data/app.db`）。启动后访问本机首页使用工作台；`/api/state` 返回当前状态。支持单工作区访问密码；公网部署必须按下方说明配置保护，多用户数据隔离尚未实现。

## 使用流程

1. 新建项目，填写想法、预算、市场和资源；未知条件可以保留未知。
2. 点击“推进当前阶段”，程序实际生成项目启动卡并保存成果。前往项目工作台查看并人工验收。
3. 在商品与供应页录入需求来源、供应核查、样品和风险材料。资料区分事实、假设与待核实。
4. 研究与选品任务可调用服务端配置的模型分析已录入资料。模型未配置时会明确报错，仍可人工提交成果与验收，不会伪造研究。
5. 样品检查强制人工参与。成本由程序以整数分计算，缺失项不输出确定贡献。满足资料闸口后才能验收。
6. 营销与实验页可保存测试计划、记录人工执行费用和复盘。活动预算总额受项目预算限制；这不等于控制外部平台的实际花费。
7. 客户与订单页可人工导入订单，防重复、核查支付、登记物流和售后退款；不会代替外部平台发货或退款。TEST- 开头订单排除在页面汇总外。
8. 导出项目可下载 JSON，包括任务、成果、经营记录和操作历史。

## 模型配置

服务端读取 `AI_API_KEY`（或已有 `OPENAI_API_KEY`）、`AI_MODEL`、`AI_BASE_URL`（默认 `https://api.openai.com/v1`），使用支持结构化 JSON 的 OpenAI Chat Completions 兼容服务。密钥不存入数据库、不返回页面，不应填写到资料和聊天记录。

配置后重启服务，在“知识与连接”给项目设置 0–20 次调用授权。每次最多输出 2000 tokens；授权是次数限制，不是金额上限，费用仍由供应商计收。撤销授权会取消排队任务、拒绝旧结果，但已发送的请求无法撤回，可能已产生费用。超时及服务重启中断不会自动重发请求，需人工确认再决定重试。

只使用 HTTPS，默认 TLS 校验；拒绝重定向，避免凭据转发。模型目前只分析导入资料，没有联网检索或外部写入工具。生成结果保留证据引用、未知项和下一步，经人验收后解锁下游。

## 测试

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
```

浏览器验收需 Playwright 和 Chromium，使用独立空数据库启动服务后运行：

```sh
PORT=3012 APP_DB=/tmp/venture-e2e.db python3 server.py
BASE_URL=http://127.0.0.1:3012 node tests/browser.cjs
```

Playwright 不在本项目运行依赖中；本云环境已提供，可用 `NODE_PATH=/opt/codex/cua_node/lib/node_modules` 找到。其他机器安装到独立测试工具目录，不必改变运行依赖。

## 数据与恢复

任务、尝试、调用授权、资料、营销、订单、实验和日志均持久化。服务重启后恢复排队任务；执行中任务标为需人工确认，避免重复调用费用。暂停或条件更正后，旧结果不会生效。

停止服务后复制 `.data/app.db` 备份；恢复时停止服务再放回，或用 `APP_DB` 指向副本。不得覆盖已有数据。测试使用临时数据库，不写入正式工作区。

## 当前边界

外部检索、真实站点发布、广告投放、支付、物流、客服连接尚未实现；14 个岗位中只有当前阶段任务具备执行入口。模型协议有受控测试，真实模型调用尚未验证，因为当前环境没有凭据。多租户认证、完整金额预算账本、生产部署与真实经营闭环未完成。

## 部署与访问

[从此仓库部署到 Render](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fyang45627-ux%2Fhidream-ai-clone)。这是部署入口，需要登录托管平台授权；不是已经上线的网站。创建服务后，从服务环境变量中获取自动生成的 APP_ACCESS_TOKEN，作为工作台登录密码。

仓库提供 `render.yaml`（免费临时预览）和 `Dockerfile`（自行部署）。默认仍仅监听本机；`APP_HOST=0.0.0.0` 公开监听时必须设置至少 24 位随机 `APP_ACCESS_TOKEN`，否则启动拒绝。

公网首页为密码登录页，使用部署环境中的 `APP_ACCESS_TOKEN` 登录；密码不填写到聊天。Render 蓝图自动生成该密码，部署后在该服务的环境变量设置中查看。Cookie 使用 HttpOnly / SameSite；平台 HTTPS 地址由 `RENDER_EXTERNAL_URL` 自动提供。其他反向代理部署需设置 `APP_PUBLIC_ORIGIN=https://你的实际域名`，用于跨站请求校验及 Secure Cookie。

`/api/health` 可匿名检查服务健康，但不返回项目资料。其他 API 受访问密码保护。这是单工作区共享密码，并非多用户认证；不要给不可信用户共享密码。

Render 免费实例没有持久磁盘，本地 SQLite 数据在休眠、重启或重新部署时可能丢失；界面明确显示临时预览提示。仅用于测试体验。长期使用需先选定并配置持久化数据库或挂载磁盘；不要将免费预览当生产经营部署。
